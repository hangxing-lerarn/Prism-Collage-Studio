**Prism Collage Studio** 是一款基于 **Electron + 原生 HTML5 Canvas 2D 平面图拓扑引擎** 打造的桌面端创意分镜与异形拼图工作台。

区别于传统固定网格拼图工具，本项目基于实时平面半边图（Planar Half-Edge Subdivision）求解器，支持在**任意异形外框或提取出的人物剪影轮廓**内部，使用直线、折线、弧线、手绘曲线或玻璃碎裂刀自由切分出任意多边形分镜，并内置双重曝光融合、磨砂防裁切补边、可定焦氛围线条与 3D 镭射徽章/卡片实时预览。

## ✨ 核心功能亮点

### 1. 创意剪影 · 提取人物轮廓生成异形画框
独立内置交互式人物轮廓提取工作台，可将角色立绘轮廓一键转化为多格分镜总外框或自由叠放相框：
- **三合一初筛引擎**：
  - **智能防漏抠底**：四边多点背景采样漫水填充 + RGB 最大通道 **Sobel 浅边防漏锁**，有效防止浅色头纱、光环在浅色背景上被误吞；
  - **透明通道直提**：自动识别 PNG 透明底立绘并提取主轮廓；
  - **手动套索圈选**：多边形点选快速圈定复杂背景中的主体范围。
- **像素级放大与画笔精修**：
  - 支持 **`Ctrl + 滚轮`** 围绕光标无级缩放（`75% ~ 800%`）与 **`空格 / 中键拖拽`** 平移画面；
  - 提供 **`+ 保留主体笔`**、**`− 擦除背景笔`**、**`★ 局部原貌保留笔`**（最小 `1px` 精细修边、滚轮调笔刷、右键临时反向擦除、20 步撤回）。
- **立牌包边与无自交平滑**：圆盘形态学膨胀/收缩（`-8px ~ +20px`）自动桥接细碎发丝，配合无自交 Chaikin 圆角细分，确保任意切割顺滑稳定。
- **三种视觉融合玩法 + 双出口确认**：
  1. **纯粹剪影分镜（默认核心）**：轮廓外干净透明，轮廓内自由切分多格放置其他角色；
  2. **双重曝光叠印**：在内部多角色分镜上方 1:1 精准叠印原人物**衣褶线稿**（可选鎏金/纯白/墨线/自定义色）或**柔光虚影**；
  3. **局部原貌保留 + 裙摆分镜**：保留原角色头部/上半身（或手涂指定区域）高清原貌并自然羽化过渡至下方多格分镜；
  - 支持一键 **「设为唯一总外框（内部可切多格）」** 或 **「添加为自由剪影相框」**。

### 2. 平面图拓扑任意分镜切割（Planar Slicer）
- **基础切刀**：支持 **直线/折线切割刀 (`L`)**、**锚点 C 弧 / S 曲线刀 (`C`)**、**手绘平滑曲线刀 (`P`)**；
- **进阶拓扑交互**：画到半途双击可暂存半截刀口，第二刀与之交汇自动生成 **T 型 / Y 型分镜**；在内部画闭合圈可直接挖出**画中画内嵌子格**；
- **碎裂分镜与跨格折射**：一键生成**放射裂纹**、**斜向裂纹**与 **Voronoi 冰晶网格切分**，支持「同图跨分镜无缝铺满」与微错位玻璃折射特效；
- **边缘材质**：内置**标准漫框**、**真凹凸拼图卡扣**、**手撕纸毛边**与**复古胶卷齿孔**。

### 3. 异形总外框与自由叠放图层
- **多样化总外框**：内置矩形、圆形、斜切平行四边形、六边形、八角星芒、爱心、盾徽、邮票齿孔等预设，并支持在画布上手绘任意闭合多边形作为总外框；
- **自由叠放图层**：支持无限叠加 **自由异形相框**、**局部特写放大镜（带引线）**、**多气泡款式文字排印** 与 **矢量/自定义图片贴纸**，支持图层上下排序、显隐与锁定。

### 4. 单格氛围特效与全局风格设置
- **防裁切构图模式**：每个分镜独立支持 **「铺满裁切 (Cover)」** 与 **「完整全图 · 磨砂补边 (Contain + Frosted Backdrop)」**，竖图放横格、横图放窄格均不裁头不留白边；
- **可定焦漫画氛围线**：内置 **集中线**、**斜向速度线**、**凄美细雨线**、**星芒柔光** 4 种线型，支持点击画面对准角色眼部定焦、调节留空保护圈、切换墨黑/纯白/主题色与透明度；
- **局部留色与抽离悬浮**：一键设置「仅当前分镜全彩、其余自动黑白反差」及单块拼图翘起投影悬浮；
- **左下角「风格设置」中心**：
  - **3 套阻尼毛玻璃界面皮肤**：深邃暗色（`pro-dark`）、主题霓光（`oshi-neon`，支持自定义主题色）、奶油浅色（`creamy-light`）；
  - **6 套非破坏性画布画风预设**：原片直出、漫画张力、柔光胶片、赛博霓虹、奶油手账、暗调哥特，一键联动色调、暗角与胶片颗粒。

### 5. 3D 徽章/镭射卡片预览与超清无损导出
- **3D 实时反光预览**：自动识别圆形/方形/异形轮廓生成吧唧徽章或镭射色纸透视模型，支持**碎钻镭射膜**、**彩虹素面**、**细闪银葱**、**高透亮膜扫光**实时交互与定格导图；
- **超采样无损导出**：支持 `1x / 2x / 3x / 4x` 倍率导出（最高支持透明通道无损 PNG、高质量 JPG 与 WebP），并支持 `.prism.json` 完整工程文件保存与二次编辑。

## 🚀 快速开始

### 方式一：Windows 绿色免安装便携版（推荐直接使用）
无需安装 Node.js 或任何依赖环境：
1. 前往 [**GitHub Releases 页面**](https://github.com/hangxing-lerarn/Prism-Collage-Studio/releases/latest) 下载最新的 `Prism-Collage-Studio-v1.1.0-win64-portable.zip`；
2. 将压缩包完整解压到任意文件夹，直接双击 **`Prism拼图工作台.exe`** 即可启动。

### 方式二：从源码安装与运行

#### 环境要求
- [Node.js](https://nodejs.org/) `>= 18.0.0`（推荐 LTS 版本）
- Git

#### 启动步骤

```bash
# 1. 克隆仓库
git clone https://github.com/hangxing-lerarn/Prism-Collage-Studio.git
cd Prism-Collage-Studio

# 2. 安装依赖
npm install

# 3. 启动桌面工作台
npm start
```

> **Windows 快捷启动提示**：完成 `npm install` 后，在 Windows 下也可以直接双击根目录的 **`启动拼图工作台.vbs`**（无黑框静默启动）或 **`启动拼图工作台.bat`** 快速打开软件。

## ⌨️ 常用快捷键速查

### 主画布工作区
| 快捷键 / 操作 | 功能说明 |
| :--- | :--- |
| `V` | 切换至「选择 / 移图模式」（拖拽调整分镜内立绘构图或移动自由图层） |
| `L` / `C` / `P` | 快速切换「直线/折线刀」/「锚点曲线刀」/「手绘平滑刀」 |
| `鼠标滚轮`（置于分镜上） | 直接无级缩放当前分镜格内的角色立绘 |
| `空格 + 左键拖动` / `中键拖动` | 平移主画布视野 |
| `Ctrl + 滚轮`（置于画布空白处） | 缩放主画布全局视图 |
| `方向键 ↑ ↓ ← →` | 选中装饰贴纸时按 `1px` 像素级微调对位（按住 `Shift` 为 `10px`） |
| `Ctrl + Z` / `Ctrl + Y` | 撤销 / 重做历史步骤 |
| `Delete` / `Backspace` | 删除当前选中的切割线或自由叠放图层 |
| `Esc` / `Enter` | 取消当前绘制草稿 / 闭合确认当前手绘切割或轮廓 |

### 人物轮廓提取工作窗
| 快捷键 / 操作 | 功能说明 |
| :--- | :--- |
| `Ctrl + 滚轮滑动` | **以鼠标指针为中心无级放大/缩小画面**（`75% ~ 800%`） |
| `普通滚轮滑动` | 快速增大 / 缩小修补画笔半径（`1px ~ 45px`） |
| `空格 + 左键拖动` / `中键拖动` | 放大状态下顺滑平移画面视野（自动防误涂） |
| `按住右键拖动` / `Alt + 左键` | 临时反向擦除（保留笔秒变擦除笔，松开自动恢复） |
| `Ctrl + Z` | 撤回上一笔涂抹修补（支持 20 步历史） |
| `Ctrl + 0` | 一键复位至 `100%` 适屏视图 |

## 📂 项目目录结构

```text
Prism-Collage-Studio/
├── main.js                     # Electron 主进程（窗口生命周期、本地图片/文件夹读取、导出与工程持久化 IPC）
├── preload.js                  # ContextBridge 安全预加载桥接层
├── package.json                # 项目配置与启动脚本
├── 启动拼图工作台.vbs            # Windows 无控制台静默快捷启动脚本
├── 启动拼图工作台.bat            # Windows 批处理启动脚本
└── src/
    ├── index.html              # 主工作台界面结构、SVG 矢量图标库与五大交互模态窗
    ├── styles.css              # 三主题毛玻璃视觉系统、阻尼抽屉动效与响应式组件样式
    ├── app.js                  # 核心状态机、交互工具控制器、历史栈、模板持久化与全局风格管理
    ├── engine/
    │   ├── planarSlicer.js     # 平面图半边拓扑分割求解器（支持折线/曲线交汇、内嵌挖洞与碎裂生成）
    │   ├── silhouettes.js      # 预设异形外框生成、Chaikin 无自交平滑与几何辅助算法
    │   ├── renderer.js         # 多层离屏合成渲染管线（独立图层 destination-in 裁切、边缘材质与超清导出）
    │   ├── fxLab.js            # 单格特效实验室（磨砂补边、4种可定焦氛围线条、局部留色、玻璃折射）
    │   ├── templates.js        # 内置分镜构图模板库与自定义模板序列化
    │   └── stickers.js         # 矢量贴纸装饰渲染器与自定义 PNG 贴纸管理
    └── ui/
        ├── silhouetteModal.js  # 创意剪影：人物轮廓防漏分割、画笔修补、立牌外扩与三种融合叠加引擎
        ├── cropModal.js        # 单格与自由相框高精度独立精裁弹窗
        └── goods3dModal.js     # 3D 徽章与四款镭射膜实时光影预览引擎
```
